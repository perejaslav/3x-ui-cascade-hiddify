# 3x-ui-cascade-hiddify

Русскоязычный Hermes Skill для настройки каскадной схемы из двух серверов с 3X-UI/Xray:

**Windows 11 + Hiddify → российский сервер → зарубежный сервер → интернет**

## Что делает скилл

Скилл описывает безопасный и проверяемый сценарий настройки каскада, где:

- пользователь в Hiddify подключается только к российскому серверу;
- российский сервер выступает входной точкой;
- зарубежный сервер выступает служебной точкой соединения и конечным выходом в интернет;
- профиль Hiddify не должен указывать на зарубежный сервер как на основной адрес.

## Внутри скилла

- сбор данных перед началом работ;
- проверка SSH-доступа по уже настроенному ключу;
- preflight-проверки;
- резервное копирование перед изменениями;
- план отката;
- проверка или установка 3X-UI на обоих серверах;
- настройка inbound/outbound/routing;
- создание отдельного служебного клиента на зарубежном сервере;
- создание пользовательского профиля для Hiddify на российском сервере;
- проверка маршрута трафика и внешнего IP;
- диагностика типовых ошибок;
- Docker-тестирование каскада на одной машине (без реальных серверов);
- pitfalls по 3X-UI API (CSRF, формат `xraySetting`, конфликт портов, SQLite WAL).

## Структура репозитория

- `SKILL.md` — основной файл скилла.
- `references/cascade-implementation-notes.md` — компактные заметки по внедрению.

## Безопасность

Скилл запрещает:

- публиковать секреты в отчётах и логах;
- отключать firewall полностью;
- перезаписывать конфигурации без backup;
- выдавать служебный foreign-клиент как основной Hiddify-профиль.

# Техническое задание: 3x-ui-cascade-hiddify 2.1.0

Дата: 2026-10-26. Область: только локальный репозиторий. Никаких подключений к рабочим VPS, push или merge.

## Цель

Устранить подтверждённые ошибки безопасности тестового стенда, конфигурационного контроля и CI; обновить ориентир тестирования до 3x-ui 3.11.0 (Xray-core 26.10.21). Текущие релизы: https://github.com/MHSanaei/3x-ui/releases .

## Критерии приёмки

1. Ни один тестовый Docker-порт не публикуется на всех интерфейсах; ресурсы чужих запусков не удаляются автоматически.
2. `THREEXUI_VERSION` действительно выбирает образ; stable и latest в CI различаются; pinned baseline — 3.11.0.
3. Невыполненная часть плана и неожиданные изменения конфигурации дают отказ, а не ложный PASS; состояние отката явно отражается в диагностике.
4. Вывод парсера X25519 не раскрывает приватный ключ.
5. Есть автономные детерминированные регрессионные тесты и отдельная проверка Docker-каскада.
6. README/SKILL/CI согласованы; внешние VPS не изменены.

## Отчёт локальных проверок (2026-10-26)

- 3x-ui v3.11.0 / Xray-core v26.10.21: Docker integration 13/13 PASS.
- Full rollback rehearsal: 9/9 PASS.
- Negative scenarios: 22/22 PASS.
- VLESS+Reality two-hop: 11/11 PASS, один дополнительный DNS probe пропущен с WARN из-за fake-ip DNS на Windows хосте.
- Реальный Hiddify Windows не использовался; тестовый клиент — Xray в Docker.

## Ограничения и остаточные проверки

Проверка на Docker **не эквивалентна** тестированию реального Hiddify или VPS. Для production-приёмки требуются действующие серверы, замеры DNS/IPv6/UDP, проверка IP выхода, сертификатов и сетевого экранирования. Эти действия отложены до отдельного разрешения владельца.

## Приоритетные будущие улучшения

- Привести IPv6/UDP/DNS проверку к воспроизводимым end-to-end сценариям с независимыми сервисами.
- Ввести изолированный сетевой тест с настоящим Hiddify для Windows.
- Добавить проверку работоспособности восстановленного Xray после rollback, а не только состояния шаблона/доступности интернета на хосте.
- Отделить production orchestration от Docker test harness и провести ручную ревизию инструкции на всех поддерживаемых API.
